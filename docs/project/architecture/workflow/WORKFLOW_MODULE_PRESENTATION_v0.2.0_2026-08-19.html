Modulübersicht der Zielarchitektur

Vollständige Präsentation der katalogisierten Komponenten der Masterarbeitssoftware. Sie verbindet aktuellen fachlichen Reifegrad mit der vorgesehenen Zielarchitektur.

Lesart: Der verbindliche Ablauf lautet PreProcess → Kernprozess → PostProcess. Querschnittsmodule unterstützen alle Bereiche, sind aber keine zusätzliche Fachphase. Durchgezogene Prozessknoten sind Teil des aktuellen Umfangs; Statuschips zeigen ihren fachlichen Reifegrad.

Zielprozess auf einer Seite
